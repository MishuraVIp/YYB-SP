# Memory Bank: Мемориальный сайт

## Описание проекта
Светлый мемориальный сайт в память о дорогом человеке. Сайт содержит историю жизни, фотографии, воспоминания и гостевую книгу. 

## Текущий статус
- **Дизайн**: Переход от минималистичного "светлого песка и глубокого сланца" к **насыщенному черно-белому** (монохромному) дизайну.
- **Особенности нового дизайна**:
  - Чередование темных и светлых секций.
  - Использование шума (grain) для кинематографичного/ретро эффекта.
  - Высокий контраст, крупные заголовки с засечками (Playfair Display).
  - 100% обесцвечивание изображений с двойными рамками и четкими границами.
  - Серебристые "партиклы" вместо золотых.

## Структура
- `index.html` - Основная разметка (Hero, Биография, Галерея, Гостевая книга).
- `css/style.css` - Стилизация, содержит переменные для цветов, анимации (fade-in, particles).
- `js/app.js` - Логика интерактивных элементов (скролл, лайтбокс).

## Важные моменты
- Шрифты: `Playfair Display` для заголовков, `Inter` для основного текста.
- Эффекты: Сайт использует `backdrop-filter` для навигации, параллакс/плавающие элементы на фоне, появление элементов при скролле.
- Вся палитра задается в `:root` в `style.css`. Изображения должны быть строго ЧБ для сохранения стилистики.
